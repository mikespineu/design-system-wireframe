Design System Wireframe Slider · DS-23 · draft

Slider

Pick one number by dragging a single thumb along a track. Built on Radix Slider. Works with uniform steps (min, max, step) or a custom list of allowed values (e.g. 1, 2, 3, 5, 8, 10). A value bubble shows above the thumb while dragging (default); it can be made always visible, and then it is an editable input. An optional numeric input (showInput, off by default) can sit next to the track instead. Typed values snap to the nearest allowed value. Optional − / + stepper buttons, three mark variants (steps, none, ends) and a unit are covered in sections 04 and 06. Section 01 shows the four explored directions; A (Hairline) is chosen, and sections 02 to 07 detail it.

04

Steps, marks & snapping

Uniform scales use min, max and step. Custom lists use values[]; each value gets an equal share of the track (ordinal spacing), because the list maps to Radix index steps 0…n−1. Three mark variants via marks: "steps" (tick at every step), "none", and "ends" (ticks and labels at min and max only), plus an explicit list. Ticks under the fill are black; the current value's label is black 500. Shown with showInput so the typed value and snapping are visible; marks work the same without it.

05

Options · bubble, Field

bubble = "auto" (default): a read-only bubble above the thumb while dragging or keyboard-focused. bubble = "always": the bubble stays visible and is an editable input (type, then Enter or blur snaps to the nearest allowed value); it replaces the attached input, so it cannot be combined with showInput. bubble = "off": no bubble. SliderField wraps the control in Field: label, hint, error and required marker, as TextField does.

06

Stepper · marks · units

stepper adds a − and a + button that ride along the track with the thumb. The thumb becomes a value block showing the value with its unit. Each press moves exactly one step (±step, or the previous / next list item), clamped; the button at an end is disabled. In Hairline the reference's orange pill and round buttons become square, black on white: 2 px black value block, 1 px black buttons. The root is inset by button + 4 px + half the block on both sides, so the group never overflows at min or max. Ticks are drawn across the track (the "dots"), black behind the thumb, gray ahead. Buttons are real buttons but not tab stops; the thumb's arrow keys step the same way.

07

Touch · lg

At lg the whole root is a 48 px tall, full-width target; pressing anywhere moves the thumb there. The optional input and the bubble input are 44–48 px. During a touch drag the bubble (auto or always) grows to 48 px with 22 px type and lifts so its bottom sits 48 px above the thumb, clear of the fingertip; at the ends it slides inward instead of leaving the screen. Dashed outlines show hit areas; the dashed oval is a fingertip, not part of the design.

09

Out of scope

Range / two thumbs (or more) · press-and-hold repeat on stepper buttons · rounded pill or circular stepper buttons · vertical orientation · read-only · logarithmic or proportional spacing for custom lists · clickable mark labels · a value bubble on hover · spin buttons on the input.
