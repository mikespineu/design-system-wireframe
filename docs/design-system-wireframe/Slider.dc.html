Design System Wireframe Slider · DS-23 · draft

Slider

Pick a number, or a range, by dragging along a track. Built on Radix Slider. Works with uniform steps (min, max, step) or a custom list of allowed values (e.g. 1, 2, 3, 5, 8, 10). An optional numeric input sits next to the track and snaps whatever is typed to the nearest allowed value. Section 01 explores four directions; sections 02 to 07 detail the recommended one (A, Hairline).

Steps, marks & snapping

Uniform scales use min, max and step. Custom lists use values[]; each value gets an equal share of the track (ordinal spacing), because the list maps to Radix index steps 0…n−1. Ticks under the fill are black; the current value's label is black 500.

08

Out of scope

Vertical orientation · more than two thumbs · minimum distance between range thumbs · read-only · logarithmic or proportional spacing for custom lists · clickable mark labels · a value bubble on hover · spin buttons on the input.
