Design System Wireframe Button · DS-32 · draft

Button

The Button family grows by three things: icon slots on Button (leading, trailing or both), variants, loading and a pressed state on the existing IconButton, and a ButtonGroup that joins a Button and an IconButton into one unit (Add to cart + Wishlist). Same height (44 px), same square corners, same 2 px black focus ring. No new tokens. Icons are passed in as components; the heart is a consumer icon, not a system glyph.

01

Family & API

Three components. Button and IconButton share variants, colours and the loading behaviour. ButtonGroup is layout and semantics only: it adds role="group", a name, the attached seam and a group-wide disabled. It has no keyboard model of its own.

Anatomy & size

One size, 44 px, as today. Icons sit inside the existing padding with an 8 px gap to the label, so adding an icon makes a button 24 px wider and never taller. Button icons are 16 px (they sit next to 14 px mono text); IconButton keeps its 18 px icon. The spinner takes the icon size of its host.

06

Loading behaviour

Loading is a busy action, not a disabled one. The button keeps its colours, width, name and place in the tab order; only activation is blocked. It uses aria-disabled, never the native disabled attribute, so focus is not thrown to <body> when loading starts on a focused button.

IconButton · Pressed

A toggle IconButton (pressed or defaultPressed set) shows pressedIcon while pressed: heart outline → heart filled. Secondary and ghost also get a 2 px black border, so the state never depends on the glyph alone. Primary keeps its black fill and relies on pressedIcon (a black border cannot show on black). aria-label stays "Add to wishlist"; aria-pressed carries the state.

09

ButtonGroup · Attached

attached: children touch and every child after the first is pulled back 1 px (margin-inline-start: -1px), so neighbouring borders collapse into one shared 1 px line. A hovered or pressed child is raised (z-index: 1) and a focused child higher still (z-index: 2), so its border and ring are never covered by a neighbour. The group itself draws nothing.
