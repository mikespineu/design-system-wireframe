Textarea

Multi-line sibling of Input. Same border, fill, focus ring, invalid and disabled treatment, same Field wiring (label, hint, error). One row is exactly 44 px, so a one-line textarea lines up with an Input. Size is a row count; resize is vertical only; an optional character counter sits in the hint row.

01

Sizes

Size sets the starting number of rows. Type stays body 16/26 at every size, like Input. Height = rows × 26 + 2 × 8 padding + 2 × 1 border.

03

Resize

Width always fills the container; only height changes. The starting rows are the minimum height. Disabled and read-only never resize.

resize="vertical" (default)native handle, drag down
Min height = rows. No max. Handle is pointer-only; keyboard users rely on scrolling.
resize="none"fixed height, scrolls
For tight layouts (dialogs, table cells). Content scrolls vertically.
resize="auto"grows with content · rows 2 to maxRows 6
Grows one row at a time from rows to maxRows, then scrolls. No handle.

05

Keyboard

KeyAction
Tab / Shift TabMove focus in / out. Never inserts a tab character. Disabled is skipped; read-only is a stop.
Enter / Shift EnterInsert a new line. Never submits the form.
← → ↑ ↓ Home End PgUp PgDnNative caret movement and scrolling (also in read-only).
Cmd/Ctrl A, C, X, V, ZNative select all, copy, cut, paste, undo. Cut and paste do nothing in read-only.
EscNo action (bubbles, so a parent Dialog can close).
