Icon

Bring your own icons. The design system ships no public icon set. Icon renders any SVG icon component, and every component that draws an icon inside itself falls back to a small private set of default glyphs. Default glyphs are drawn on a 24 px grid, stroke only, butt caps, miter joins, in currentColor. A consumer can swap any glyph per instance (prop) or for a whole subtree (IconProvider).

01

Model

Four public pieces: the IconComponent contract, createIcon for hand-made SVGs, IconProvider to replace default glyphs for a subtree, and useIcon which resolves one role. Resolution order is prop > provider > default; the first one that is defined wins.

IconComponentthe contract
type IconComponent = ComponentType<IconComponentProps>;

interface IconComponentProps {
  width?: number | string;      // always passed, px
  height?: number | string;     // always passed, px
  className?: string;           // forwarded to <svg>
  strokeWidth?: number | string;// honored by stroke sets
  role?: string; focusable?: 'true' | 'false';
  'aria-hidden'?: boolean | 'true' | 'false';
  'aria-label'?: string; 'aria-labelledby'?: string;
}
// Must render exactly one root <svg>, paint with
// currentColor, and spread these props onto it.
Lucide, Tabler, Phosphor and Heroicons components satisfy it as they are. No adapter needed.

Drawing rulesall glyphs
24 × 24 viewBox, 2 px padding, 20 px live area. Circles r 10, centered. Crosses and dashes 5 → 19. Butt caps, miter joins (SVG defaults; set explicitly). Dots are 2-unit dashes, never h.01 round dots. No fill, stroke: currentColor. Chevrons are reserved for upcoming Select, Accordion and Pagination; no current component uses them.

Sizes × strokes, next to Lucide, Tabler, Phosphor, Heroicons

Every default glyph at 12, 14, 16, 18, 20 and 24 px with stroke 1.5 and 2, above the equivalent glyph of each library in the same sizes and strokes. Library glyphs are faithful inline approximations (no CDN). Lucide, Tabler and Heroicons are 24-grid stroke sets with round caps; Phosphor is a 256-grid set with weights instead of a stroke, so its rows show regular (≈ 1.5) and bold (≈ 2.25). Reading the tableslegend
Default rows (gray band): the private glyph, butt caps, miter joins. Boxed cell: the stroke a component passes at that size. 2 at 12 to 16 px, 1.5 at 18 px and up; rendered line never thinner than 1 px. · lib: the library's own default. The system passes strokeWidth to every icon in a slot, so Lucide, Tabler and Heroicons render at the system weight. Phosphor draws filled outlines; strokeWidth has no effect. Pick a weight in the provider (regular ≈ 1.5, bold ≈ 2.25). At 12 px, Heroicons 1.5 renders a 0.75 px line. This is why the system passes stroke 2 at small sizes.
04

Sizes

Public scale for Icon size: sm 12, md 16 (default), lg 20, on the 4 px grid; any number is also accepted. Two component-local sizes stay where they are today: 14 (inline with 13/20 caption text) and 18 (inside the 44 px IconButton). 24 is the drawing grid, 1:1. Stroke follows size: 2 at 16 px and below, 1.5 at 18 px and above.

08

Keyboard

KeyAction
Tab / Shift+TabNever stops on an icon. Every icon is focusable="false" with no tabindex. Focus goes to the control that contains it (IconButton, Dialog close, Tag remove), and the ring is drawn on that control.
Enter / SpaceHandled by the control (activate IconButton, close Dialog, remove Tag, toggle Checkbox). An override icon never adds handlers.
Esc, arrows, Home / EndUnchanged. Owned by Dialog, Slider and Radix. Swapping an icon cannot change keyboard behavior.
09

Accessibility

Inside a componentalways decorative
<button aria-label="Close">
  <svg aria-hidden="true"
       focusable="false" …/>
</button>
The component passes aria-hidden and focusable to whatever icon wins. The name stays on the control.
Standalone Icondecorative or labeled
<Icon icon={Check} />
// → <svg aria-hidden="true" …>

<Icon icon={Check} label="Paid" />
// → Radix AccessibleIcon:
//   <svg aria-hidden="true"…>
//   <span class=sr-only>Paid</span>
Label only when the icon is the only carrier of meaning (status in a table cell).
nullAlert only
<Alert icon={null} />          // ok
<Dialog closeIcon={null} />    // type error
<Tag removeIcon={null} />      // type error
<IconProvider icons={{ close: null }}> // type error
Elsewhere the icon is the only visual of an icon-only control, a checked state, or the non-color cue of an error.
