Design System Wireframe Dialog · DS-19 · draft

Dialog

Modal panel over a 50 % black overlay. Square corners, no shadow: the panel separates from the page by a 1 px black border and the dimmed ground. Header holds the title, optional description and the close button; the footer holds right-aligned actions over a gray-200 divider. Built on Radix Dialog.

01

Sizes

Size sets the panel max width only; padding, type and parts are identical. The panel is width 100 % of the viewport minus 16 px gutters on each side, so on narrow screens every size becomes full width minus gutters. Max height is viewport minus 2 × 48 px; the body scrolls beyond that.
