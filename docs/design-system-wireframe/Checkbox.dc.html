Design System Wireframe Checkbox · DS-13 · draft

Checkbox

Square box with a 2 px black border, label to the right. Checked and indeterminate fill black with a white mark. Same focus ring, invalid and disabled treatment as Field controls. A row is 44 px tall at md so it lines up with Input. CheckboxGroup wraps several in a fieldset with a legend, hint and error.

01

Sizes

Size sets the box and the row (hit area) height. The whole row, box plus label, is the click target.

smbox 16 · row 32 · gap 8 · text 15/24
Dense desktop tables and filters. Meets WCAG 2.5.8 (24 px), fine pointers only.
md (default)box 24 · row 44 · gap 12 · text 16/26
Forms and touch. Row = control height (44 px).

03

Label

Label always sits to the right of the box (left in RTL), body text, not the uppercase Field label. Long labels wrap and the box aligns to the first line. Optional description goes under the label in caption gray-600.

CheckboxGroup

fieldset + legend. Legend uses the Field label style; hint below legend; error below the options. Options stack vertically with no extra gap (rows are 44 px). Optional horizontal layout with 24 px gaps for short options.
