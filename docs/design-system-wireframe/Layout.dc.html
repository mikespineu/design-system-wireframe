Design System Wireframe Layout · Stack & Grid · DS-35 · draft

Layout

Two invisible layout primitives. Stack puts children in a line, vertical or horizontal, with a gap from the spacing scale. Grid puts children in 1, 2, 3, 4, 6 or 12 equal columns. Both draw nothing themselves: no color, border, padding or radius. Gap only takes --ds-space-* steps. Every layout prop can change at the sm / md / lg breakpoints. Both render a div by default, take as for another element, or asChild to style their only child (Radix Slot).

Keyboard · focus order

Stack and Grid are never focusable and handle no keys. Tab moves through their focusable children in DOM order, which is always the visual order: there is no reverse direction, no order prop and no dense grid packing. Badges show the Tab sequence; the ring is the standard 2 px black focus ring on the child, 2 px offset.
