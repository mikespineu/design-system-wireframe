Design System Wireframe Foundations · v0.2

Foundations

White ground. Gray accents. Black for ink and action. Muted green and red only for feedback. Photography is always monochrome. Titles are set in Red Hat Mono; everything else in Red Hat Text. Every swatch, size and shape on this board reads a --ds-* token, so it follows the theme: set data-theme on the page to see another one.

06

Photography

filter: var(--ds-photo-filter)
Do 100% grayscale, slight contrast lift (+10%), visible film grain. Square corners. Crops 4:5, 1:1, 16:9. Mono caption beneath, never over the image.
Don't Color or partial color, sepia, duotone tints, gradient overlays, drop shadows, rounded corners, text placed on busy areas.
