Design System Wireframe Theming · DS-26 · draft

Theming

The theme contract: 87 flat roles a theme may override (color, font, weight, type scale, radius, shadow, shape). Defaults reproduce today's Wireframe exactly. Every panel below renders the same components from the same CSS; the only difference between panels is a block of role overrides on the panel root. That is the whole API.

01

The contract at a glance

Seven groups. Components read roles only; primitives (palette, spacing) and component-local properties are not themeable. New roles are marked; their definitions are under Token requests in the spec.

Knob · Brand color

Four color roles. Everything that means "action" or "selected" follows: primary button, checked box, slider range, solid tag, badge, focus ring, pressed fills. Text, borders and feedback stay neutral. The indigo is an illustrative value for this canvas, not a token.

Overrides

  • --ds-color-primary#3730A3 · white on it 9.9:1
  • --ds-color-primary-hover#312E81 · 11.4:1
  • --ds-color-primary-contrast#FFFFFF
  • --ds-color-focus#3730A3 · 9.9:1 on white

createTheme() derives these from one brand color (50–900 scale) and checks the pairs.

04

Knob · Fonts

Three family roles. Headings (h3, dialog title) take a serif, body and UI labels take the system sans. Numerals in the slider bubble stay on font-mono, which this panel does not override.

Overrides

  • --ds-font-headingGeorgia, 'Times New Roman', serif
  • --ds-font-bodysystem-ui, -apple-system, 'Segoe UI', sans-serif
  • --ds-font-labelsystem-ui, -apple-system, 'Segoe UI', sans-serif

Label case and tracking are type-scale roles, not font roles: the field label stays uppercase here.

07

Knob · Shadow

Three steps, default none. sm lifts the slider thumb, md the floating value bubble, lg the dialog panel. Buttons, fields, alerts and tags stay flat in every theme; borders still carry the edge, so contrast does not depend on shadow.

Overrides

  • --ds-shadow-sm0 1px 2px rgb(0 0 0 / 0.12)
  • --ds-shadow-md0 4px 12px rgb(0 0 0 / 0.14)
  • --ds-shadow-lg0 16px 40px rgb(0 0 0 / 0.2)

Illustrative values; Wireframe keeps none.

Knob · Dark

data-theme="dark" overrides the 30 color roles and sets color-scheme: dark. Fonts, type, radius and shadow stay default. Ground gray-900, ink gray-50, light primary with dark text, the same muted green and red with their light-mode fg and border swapped and new deep backgrounds. Overlay rises to 70 %.
