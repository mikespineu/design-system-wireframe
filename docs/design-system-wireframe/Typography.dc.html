Typography

The type scale as two components. Heading is Red Hat Mono 500 in black: level (1–6) picks the element for the document outline, size picks the look, and the two are independent. Text is everything else: five sizes, three weights, Red Hat Text or Mono, four tones, and single-line truncate or multi-line clamp. Neither is interactive; both compose through asChild (Radix Slot).

01

Choose level from where the heading sits in the page outline; choose size from how loud it should look. Every level has a default size, so most headings need only level. The chip on the right of each example is the element that is rendered.

07

Truncate · Line clamp

Text wraps by default. truncate keeps one line and ends it with an ellipsis. lineClamp={n} keeps n lines and ends the last with an ellipsis. Both are on Text and Heading and are mutually exclusive. The dashed frame is the container (280 px). The full string stays in the DOM, so it is copied, found and read by screen readers in full.

08

States · Focus

Heading and Text are static: no hover, pressed, selected, disabled or invalid state, and they are not in the tab order. The only focus they show is as the target of a skip link or of focus management (tabIndex={-1}). Interactive children such as links own their own hover and focus styles; the artboards show how they compose.

Do · dialogs and reusable partslevel comes from the caller

A dialog title is h2 (Radix Dialog.Title); its sections start at h3. A reusable card or section takes the level as a prop instead of hardcoding it, because it may sit under an h1 on one page and an h2 on another.

<ProductCard headingLevel={3} /> → <Heading level={headingLevel} size="md">

One h1 per page, the page title. Visually hidden h1 is fine when the design has no visible title.
