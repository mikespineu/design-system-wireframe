Design System Wireframe Toggle · DS-5 · draft

Toggle

A small family instead of one overloaded control. Switch is the boolean on/off (Radix Switch). SegmentedControl and TileGroup are single-select choice groups (Radix RadioGroup): a value is always selected, the strip scrolls horizontally when it does not fit, and it never wraps. Square corners, black ink, gray fills; the configurator's orange accent is translated to black (see Token requests in the spec).

01

Three components, one per job. The two choice groups share the same row layout (label, control, optional help), the same Radix primitive and the same overflow behaviour; they differ only in how an option looks.

10

Overflow · horizontal scroll

When options do not fit, the strip scrolls on X. It never wraps. A 24 px edge fade appears only on the side that has more content. Scroll-snap aligns items to the start edge; the selected item is scrolled into view on mount and whenever it changes (arrow keys, programmatic value).
