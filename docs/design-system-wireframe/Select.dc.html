Design System Wireframe Select · DS-17 · draft

Select

Pick one value from a list. The closed trigger is an Input: 44 px, gray-300 border, body 16/26, same hover, focus, invalid and disabled treatment, wired by Field (label, hint, error). It opens a square listbox with a 1 px black border, no shadow, below the trigger. Options can carry a leading emoji (flags), can be split into "Top choices" and the rest, and can be filtered by an optional search field. Built on Radix Select; the search variant uses Radix Popover with an ARIA combobox. On touch-first devices it renders a native <select> from the same props.

01

Anatomy & size

One size, md, like Input: the trigger is 44 px tall at every width and fills its container. The open list matches the trigger width (wider only if an option needs it, up to the viewport), opens 4 px below it, and is capped at 7.5 rows (330 px). The half row at the cut tells the user the list scrolls.

05

Search (optional)

searchable adds a search field at the top of the open list. It is a 44 px row with a search icon and a gray-200 bottom divider that turns black while the field has focus; it stays put while the list scrolls. Typing filters by label (and keywords), ignoring case and accents. While a query is typed, group labels and the separator are hidden and matches are listed flat, top choices first. The first match is highlighted.

06

Native on touch

On touch-first devices, matched by (hover: none) and (pointer: coarse), Select renders a native <select> from the same props. The closed control looks identical (appearance none, same border, padding, chevron). The open list is the OS picker: top choices become an <optgroup>, the emoji is part of the option text, and there is no search field.

07

Layering & position

The list renders in a portal at the end of body, so a scrolling or clipped parent (a Dialog body, a table cell) never cuts it. It sits above Dialog (overlay 50, panel 51) at z-index 60. It opens below the trigger, start-aligned, 4 px gap, and flips above when there is not enough room below; it keeps 8 px from the viewport edges.

08

Keyboard

The trigger is one tab stop. While the list is open, focus stays in the list (Tab does nothing) until a choice is made or Esc is pressed; focus then returns to the trigger.
