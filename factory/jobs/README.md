# Factory jobs

One file per task the factory has worked on: `DS-<n>.md`, created from [`TEMPLATE.md`](./TEMPLATE.md). Each holds the task's status, current stage, links (branch, PR, canvas, Storybook), fix-loop counts, a timeline of everything that happened, and notes.

Job files are written on the task's branch while it runs and land here when its PR merges, so this folder is the factory's history. See [`../plugin/RULES.md`](../plugin/RULES.md) for the format.
