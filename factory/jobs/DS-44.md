## Notes

- Built on Radix `Dialog`; adds `side` (default right) and `size` (sm 320 / md 480 / lg 640, default md). Title and description required.
- Panel capped at viewport − 48 px; under 480 px every drawer goes full screen with stacked footer actions.
- Reuses Dialog overlay, header/body/footer spacing and close button; only difference is a 1 px border on the inner edge.
- Motion via CSS keyframes (so Radix Presence keeps the panel mounted while closing); off under `prefers-reduced-motion`.
- No swipe-to-dismiss / drag handle (no Radix primitive for gestures).
- For DS-45: jsdom never fires `animationend`; close tests may need the reduced-motion path or a stub.
- Possible follow-up: Dialog's closing fade uses a transition, so Radix unmounts it instantly and the fade never plays.
- Rev 2 (scroll): only the body scrolls; header divider is the body's top border, shown once scrolled via CSS scroll-driven animation (`@supports`; Firefox falls back to no header divider).
- Rev 2: body is always a focusable region (`tabIndex=0`, `role="region"`, named by the title) so it scrolls from the keyboard; costs one extra Tab stop in short drawers (alternative: ResizeObserver toggle). Reviewer decision.
- Rev 2: canvas uses snap points / `column-reverse` only to freeze scroll positions; marked canvas-only, builder must not copy.
- For DS-45 stories: ScrollingRight/Left/Top/Bottom/NoFooter/FullMobile, at least one with no controls in the body.
- For DS-45 tests: jsdom can't detect overflow; assert `tabindex="0"`, `getByRole('region', { name })` and Tab order directly.
- Possible follow-up: Dialog's scrolling body has the same `scrollable-region-focusable` gap.
- Canvas not yet viewed in a browser by the designer.
