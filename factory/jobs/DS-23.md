## Notes

- Chosen direction (user, canvas comment): A "Hairline" (2 px gray-500 track, black fill, square white thumb with 2 px black border). B Block, C Segmented, D Ruler explored.
- Token request: `--ds-border-width-strong: 2px` (thumb border, track, sm fill; could replace `border-2` in Input/Textarea). Approving the design approves it.
- Needs decision: additive `Field` change — Label gets an `id` exposed via new `useFieldLabelId()` hook, to label slider thumbs.
- Risk: custom value lists override Radix thumb `aria-valuenow/min/max` with real values; assumes our props win over Radix's — spec requires a test.
- Custom lists use ordinal (equal) spacing; Radix `name` not used (would submit index), wrapper renders its own hidden inputs.
- Typed input: parse (comma = decimal), clamp, snap to nearest; ties go up; invalid text reverts; Esc discards draft.
- Revision 1 (user feedback 2026-10-26): range removed (single thumb); `bubble: 'auto'|'always'|'off'` (always = editable bubble input, exclusive with `showInput`; touch drag lifts it 48 px above the finger); `showInput` default false; `stepper` −/+ buttons (tabIndex −1, one step per press, disabled at ends); `marks: 'none'|'steps'|'ends'|number[]`; `unit` string (appended in display/aria-valuetext, stripped when typed).
- Canvas height (11200) is the designer's estimate; not visually verified.
