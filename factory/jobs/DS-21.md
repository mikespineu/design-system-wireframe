## Notes

- User direction at start: Tabs is a mechanism (tab list ↔ panel switching), not a new visual. The tab list should reuse the look of an existing switcher such as `SegmentedControl` or `TileGroup`.
- Designer: no underline/ink style; `variant: 'segmented' | 'tile'` on Radix `Tabs`, sharing ChoiceGroup CSS (selectors widened to `active`/`inactive`) and an internal `useChoiceStrip` hook. Never wraps `RadioGroup`.
- Activation `automatic` by default; `manual` for slow / side-effect panels and long tile rows. Horizontal only.
- API: typed `items` array (`value`, `label`, `panel`, `disabled?`, `icon?`), required `aria-label`/`aria-labelledby`, `keepMounted`, `fullWidth` (segmented only). No new tokens.
- Open: `Components.dc.html` still shows an underline Tabs mock under Navigation (contradicts this spec, untouched). DS-22 `done_when` should mention the variants and the shared CSS / `useChoiceStrip` refactor.
